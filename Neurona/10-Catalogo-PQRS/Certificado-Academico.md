# Certificado Académico

Solicitud de certificados oficiales: notas, matrícula, grado, idioma, becas, constancias varias.

## Campos adicionales requeridos
- `tipo_certificado` — notas / matrícula / grado / idioma / beca / otro
- `destino_certificado` — entidad a la que va dirigido
- `idioma` — español o inglés

## Documentos frecuentes
- No se requieren documentos adicionales para la solicitud básica.
