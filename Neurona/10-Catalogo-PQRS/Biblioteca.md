# Biblioteca

Solicitudes, quejas o reclamos relacionados con servicios de biblioteca: préstamos, recursos digitales, bases de datos, espacios de estudio.

## Campos adicionales requeridos
- `tipo_servicio_biblioteca` — préstamo / recurso digital / base de datos / espacio de estudio / otro
- `descripcion_detallada` — descripción específica del inconveniente o solicitud

## Documentos frecuentes
- Captura de pantalla del error (si es recurso digital)
- Comprobante de préstamo (si aplica)
